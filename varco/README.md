# VARCO 반려동물 사진 분석

사용자가 올린 반려동물 사진에서 종·색상·자세를 텍스트로 추출한다.
캐릭터 템플릿 매칭, 이름 추천, 캐릭터 소개 문구에 쓴다.

## 역할 범위

**VARCO-VISION은 텍스트만 출력한다. 이미지를 생성하지 않는다.**
픽셀 캐릭터 변환은 `../pixelart/` 가 담당한다. 여기는 메타데이터만 뽑는다.

**화면 캡처 판별에는 쓰지 않는다.** 사용자 화면을 서버로 보내는 구조는
개인정보 문제가 커서 `../shorts_classifier/` 의 온디바이스 CNN으로 대체했다.
반려동물 사진은 사용자가 직접 올리는 경로라 동의 구조가 명확해 서버 전송이 정당화된다.

## 배포

서빙 코드는 이 저장소가 아니라 **BE**에 있다. 여기는 프롬프트와 평가만 관리한다.

```
vllm serve NCSOFT/VARCO-VISION-2.0-1.7B --port 8000
```

## 라이선스

VARCO-VISION-2.0은 **CC-BY-NC-4.0(비상업)**. 교내 대회·연구는 문제없으나
상업적 출시로 가면 재검토가 필요하다. 출처 표기(BY) 의무도 있다.
