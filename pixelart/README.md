# 픽셀 캐릭터 변환

반려동물 사진을 픽셀 스프라이트로 바꾸는 파이프라인.

## 이 디렉터리의 목적

`reference.py` 는 **Kotlin 이식용 기준 구현**이다. 최종 코드가 아니다.

파이썬에서 파라미터를 빠르게 튜닝해 확정한 뒤, 같은 알고리즘을 앱의 `Bitmap` 연산으로
옮긴다. Kotlin에서 매번 빌드하며 픽셀 크기를 바꿔보는 것보다 훨씬 빠르다.

## 파이프라인

```
사진
 → 배경 제거      (앱: ML Kit Subject Segmentation / 여기: rembg)
 → 피사체 크롭     투명 여백을 잘라 격자를 꽉 채운다
 → 다운샘플       NEAREST 로 48px 격자
 → 팔레트 양자화   MEDIANCUT 16색
 → 외곽선         1px 테두리
스프라이트
```

**생성형 모델은 쓰지 않는다.** 전부 결정론적 이미지 연산이라 온디바이스에서 즉시 돌고,
비용이 없고, 같은 입력에 같은 결과가 나온다. 계획서의 "외부 생성형 AI API 미사용"과도 맞는다.

## 사용

```
python reference.py samples/dog.jpg --pixel-size 48 --colors 16
```

`_pixel.png`(실제 스프라이트)와 `_preview.png`(8배 확대)가 나온다.

## 튜닝 포인트

| 파라미터 | 영향 |
|---|---|
| `--pixel-size` | 32=거칠고 귀여움, 64=디테일 살지만 픽셀 느낌 약해짐 |
| `--colors` | 8=레트로, 16=무난, 32=사진에 가까워짐 |
| `--no-outline` | 테두리를 빼면 배경에 묻힌다. 오버레이 용도라 켜두는 걸 권장 |

외곽선 색은 **피사체 밝기에 따라 자동으로 뒤집힌다.** 평균 휘도가 90 미만이면 밝은 테두리를,
그 이상이면 어두운 테두리를 쓴다. 검은 고양이에 어두운 테두리를 두르면 실루엣으로 뭉개지는
문제가 실제로 재현되어 넣은 처리다.

여러 동물 사진(강아지·고양이·장모종·검은 털)으로 돌려보고 **가장 나쁜 결과 기준으로**
파라미터를 잡아라.

## 검증 상태

| 항목 | 상태 |
|---|---|
| 크롭 → 다운샘플 → 양자화 → 외곽선 경로 | ✅ 합성 이미지로 동작 확인 |
| 어두운 피사체 외곽선 | ✅ 자동 반전으로 해결 |
| 배경 제거 (rembg) | ❌ **미검증** — 설치 안 된 상태로 폴백 경로만 확인 |
| **실제 반려동물 사진** | ❌ **미검증** |
| ML Kit 마스크와의 차이 | ❌ 미검증 |

**합성 도형으로만 돌려봤다.** 실제 사진에서는 털 질감, 복잡한 배경, 그림자 때문에
결과가 달라진다. `pip install rembg` 후 진짜 사진으로 반드시 다시 확인하라.

### 알려진 한계

48px 격자에서 **눈처럼 작은 디테일이 불안정하다.** NEAREST 다운샘플이라 몇 픽셀 차이로
좌우 눈 크기가 달라진다. 캐릭터 인상에 영향이 크므로 눈 위치를 따로 보정하거나
격자를 키우는 것을 검토하라.

## 이식 시 주의

- `rembg`(U2-Net)와 ML Kit Subject Segmentation은 마스크가 다르게 나온다. 파라미터 튜닝용으로만 쓰고, 최종 확인은 실기기에서 하라
- `Image.NEAREST` ↔ Kotlin `Bitmap.createScaledBitmap(..., filter = false)`
- MEDIANCUT 결과가 아쉬우면 k-means로 교체. 이식 난도는 비슷하다
