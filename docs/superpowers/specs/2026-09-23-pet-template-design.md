# 반려동물 사진 → 캐릭터 템플릿 재색칠 설계

2026-09-24 · 상태: 검토 대기

## 목표

사진을 픽셀화하던 `pixelart/` 를 **대체**한다. 디자이너가 그린 견종 템플릿을 사용자가 고르고,
사진에서 뽑은 털색으로 **팔레트를 교체**해 캐릭터를 만든다.

```
캐릭터 = recolor(breeds[견종], 사진에서 뽑은 main·sub)
  견종  사용자가 카드에서 선택
  색    사진에서 자동 추출 → 사용자가 스와치로 바꿀 수 있음
```

생성형 모델은 쓰지 않는다. 전부 결정론적 연산이라 온디바이스에서 즉시 돈다.

## 에셋 현황 (디자인 드라이브 `peTox_픽셀`, 2026-09-24 확인)

| 견종 | 정지 SVG | 애니메이션 GIF | 원본 털색 |
|---|---|---|---|
| 골든리트리버 | 앞·뒤·오·왼 | 걷기, bark 4방향 | 황금 |
| 닥스훈트 | 앞·뒤·오·왼 | 오른쪽 걷기, 왼쪽 걷기 | 검정 |
| 웰시코기 | 앞·뒤·오·왼 | — | 주황+흰 |
| 허스키 | 앞·뒤·오·왼 | 오른쪽 걷기, 왼쪽 걷기 | 회색+흰 |
| 시바견 | 앞·뒤·오·왼 | — | 주황+크림 |

- SVG: Pixelorama 로 내보낸 픽셀당 `<rect fill='#rrggbb'>`. 시바만 48×48, 나머지 68×68.
- GIF: 68×68 (닥스 `walk_left` 만 72×72), 인덱스 팔레트, 6프레임.
- 견종별 색 수: 골든 42 (GIF 에만 있는 색 18), 닥스 26, 시바 21, 코기 18, 허스키 15.
- 동작 구성이 견종마다 다르다. 없는 동작은 앱이 정지 이미지로 대체한다. 디자이너와 맞출 항목이다.

## 범위

| 포함 | 제외 (필요해지면 추가) |
|---|---|
| 사진 → main·sub 털색 추출 | 견종 자동 분류기 |
| 견종별 색 역할표 (hex → 역할) | 학습 데이터셋 |
| 역할 기반 재색칠 | 이름 추천 |
| `pixelart/` 삭제, 문서 정리 | |

## 구성

```
pet_template/
  reference.py        색 추출 + 재색칠 (Kotlin 이식용 기준 구현)
  breeds.json         팔레트 스와치 + 견종별 에셋 목록·색 역할표
  assets/<견종>/       드라이브에서 받은 SVG·GIF (팀 제작물)
  test_reference.py
  README.md
```

`pixelart/` 는 통째로 삭제한다. `load_upright`, `remove_background` 는 `pet_template/reference.py` 로
옮긴다.

## 데이터 파일 `breeds.json`

```json
{
  "swatches": {"black": "#453d3e", "brown": "#6e4a32", "red": "#ca895a", "golden": "#e0a860",
               "cream": "#e8dcc0", "white": "#f2f0ea", "gray": "#8c8c8c"},
  "breeds": {
    "shiba": {
      "assets": {"front": "shiba/front.svg", "back": "shiba/back.svg", "right": "shiba/right.svg", "left": "shiba/left.svg"},
      "roles": {"#ca895a": "main", "#bd855c": "main", "#e7e2c7": "sub", "#181313": "keep", "#da94ad": "keep"}
    }
  }
}
```

- **역할 세 가지:**
  - `main` — 주 털색 계열. 사진의 main 으로 바꾼다.
  - `sub` — 보조 털색 계열. 사진의 sub 로 바꾼다.
  - `keep` — 외곽선·눈·코·귀 안쪽·혀. 그대로 둔다.
- 외곽선과 눈이 같은 hex 를 쓰는 경우가 있어 "외곽선만 밝게 뒤집기"는 hex 치환으로 할 수 없다.
  대신 털색 밝기에 하한(`MIN_FUR_L`)을 둬서 검은 털이 외곽선과 붙지 않게 한다.
- 각 역할의 **기준색은 그 역할에서 픽셀 수가 가장 많은 색**이다. 로드 시 계산하므로 적지 않는다.
- 역할표는 견종 에셋 **전체 파일**에 나오는 모든 색을 덮어야 한다. 파일마다 색이 조금씩 다를 수 있기 때문이다.
- 역할표는 `--suggest-roles` 로 초안을 뽑고, 역할별로 칠한 확인 시트를 사람이 검수해 확정한다.

## 흐름

### 1. 털색 추출 (사진 → main, sub)

1. `load_upright` → `remove_background` (앱: ML Kit Subject Segmentation)
2. 알파 > 128 픽셀만 모은다. 배경 제거 실패(None)거나 0개면 추출 실패 → 템플릿 원본색 그대로.
3. 픽셀마다 Lab 거리로 가장 가까운 스와치에 붙이고, 스와치별 면적을 센다.
   양자화를 쓰지 않는다 — Pillow MEDIANCUT 은 Kotlin 에서 재현이 어렵다.
   - 가장 넓은 색 = `main`
   - 두 번째 색 비율 ≥ `SUB_RATIO`(0.2) → `sub`, 아니면 `null`

스와치에 붙이는 이유는 두 가지다. 사진 조명 탓에 탁해진 색을 그대로 쓰지 않기 위해서이고,
사용자가 바꿀 때 고를 선택지가 필요해서다.

### 2. 재색칠 (역할표 + main, sub → 색 치환표)

역할 `r`, 기준색 `B`, 목표색 `T` 일 때 그 역할의 각 색 `C` 를 Lab 에서 이렇게 옮긴다.

```
C' = T + (ΔL, ΔA·k, ΔB·k)    Δ = C − B,  k = 0.3
```

밝기 차(명암)는 그대로 두고, 색조 차는 줄여서 목표색에 맞춘다. 스파이크에서 원본·검정·크림·갈색·회색+흰 다섯 가지로 확인했다.

- `sub` 가 `null` 이면 sub 역할은 원본색을 유지한다. 예: 검정 단색 사진 → 시바의 크림 턱받이는 그대로.
- 견종에 sub 역할이 없으면 사진 sub 는 버린다.
- 옮긴 색의 L 이 `[MIN_FUR_L(15), 100]` 에 들어가도록 어두운 쪽·밝은 쪽 ΔL 을 각각 비율로 압축한다.
  잘라내면 음영이 한 색으로 뭉개진다. 검정 스와치는 L≈27 로 둬서 음영 담을 여유를 남긴다.

결과는 **색 치환표 `{원본 hex: 새 hex}`** 하나다. 적용은 포맷과 무관하다.
- SVG: `fill` 문자열 치환
- GIF·비트맵: 디코딩한 프레임의 픽셀을 표로 치환

앱에서는 비트맵 쪽 한 가지만 이식하면 된다.

## 오류 처리

- 사진 없음, 유효성 실패(`pet_validation`), 추출 실패 → 견종 템플릿 원본색. **가입 흐름은 막지 않는다.**
- 역할표에 없는 색이 에셋에 있으면 테스트가 실패한다. 디자이너가 에셋을 바꾸면 여기서 잡힌다.

## 알려진 위험

- 흰 털이 그림자 때문에 gray 로 잡힐 수 있다. 스와치 값과 `SUB_RATIO` 는 실제 사진으로 조정한다.
- 역할표는 사람이 분류하므로 틀릴 수 있다. 견종마다 스와치 전부로 재색칠한 시트를 뽑아 눈으로 확인한다.
- rembg 와 ML Kit 마스크가 다르다. 최종 확인은 실기기에서 한다.
- 원본 털색과 목표색이 너무 멀면 명암이 어색할 수 있다. 예: 검정 닥스 → 흰색. `k` 와 밝기 범위는 확인 시트를 보고 조정한다.

## 테스트 (`test_reference.py`)

| 대상 | 확인 |
|---|---|
| 추출: 갈색 단색 합성 이미지 | main=brown, sub=null |
| 추출: 흰 70% + 갈 30% | main=white, sub=brown |
| 추출: 흰 90% + 갈 10% | sub=null |
| 추출: 완전 투명 | 실패 → 원본색 |
| 재색칠: 기준색 → 정확히 목표색 | 치환 결과 일치 |
| 재색칠: 명암 순서 유지 | main 계열 L 순서가 보존됨 |
| 재색칠: 검정·흰색 main | 음영 단계 수 유지, L ≥ MIN_FUR_L |
| 추출: 배경 제거 실패 | 원본색 |
| 역할표 커버리지 | 모든 견종·모든 에셋의 색이 역할표에 있음 |

확인 시트 스크립트 `reference.py --sheet` 는 견종 × 스와치 PNG 를 뽑는다. 눈 검수용이다.
