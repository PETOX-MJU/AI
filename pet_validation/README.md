# 반려동물 사진 유효성 판별

사용자가 올린 사진에 개나 고양이가 있는지 확인한다. **학습할 모델이 없다.**

## 방법: ML Kit Image Labeling

ML Kit 기본 이미지 라벨링 모델이 400개 이상의 라벨을 제공하며 여기에
`Dog`(인덱스 360)과 `Cat`(118)이 포함된다. 온디바이스·무료이고
이미 쓰고 있는 ML Kit 에 들어 있다.

```
사진 → ML Kit Image Labeling
     → 라벨에 Dog 또는 Cat 이 임계값 이상으로 있는가?
        예   → 통과, 픽셀화로 진행
        아니오 → "반려동물이 보이지 않아요" 안내 후 재촬영 유도
```

**학습 코드 없음. 데이터셋 없음. 라이선스 쟁점 없음.**

## 구현 (FE)

```kotlin
val labeler = ImageLabeling.getClient(
    ImageLabelerOptions.Builder()
        .setConfidenceThreshold(0.7f)
        .build()
)

labeler.process(image).addOnSuccessListener { labels ->
    val isPet = labels.any { it.text == "Dog" || it.text == "Cat" }
}
```

임계값 0.7은 출발점이다. 실제 사진으로 조정하라.

- **너무 높으면** 정상 사진이 반려당해 사용자가 막힌다
- **너무 낮으면** 사람이나 인형 사진이 통과한다

**막히는 쪽이 더 나쁘다.** 가입 단계에서 통과가 안 되면 사용자는 그냥 떠난다.
애매하면 통과시키고, 픽셀화 결과가 이상하면 사용자가 다시 올리게 두는 편이 낫다.

## 폴백

판별 실패가 가입 흐름을 막으면 안 된다. **기본 캐릭터로 진행할 수 있는 경로를 항상 열어 둬라.**
"반려동물 사진 없이 시작하기" 버튼이 항상 보여야 한다.

## 참고: 다른 동물

라벨 목록에는 `Bird`, `Bear`, `Horse`, `Turtle` 등도 있다. 개·고양이 외 반려동물까지
받으려면 허용 라벨 집합만 넓히면 된다. 코드 변경은 한 줄이다.

품종 라벨도 일부 있으나(`Dalmatian`, `Ragdoll`, `Sphynx` 등) 커버리지가 고르지 않다.
**품종 판별에는 쓰지 마라.**

## 왜 분류기를 학습하지 않는가

한때 종·털길이 분류기를 학습하는 방향으로 설계했으나 걷어냈다. 필요한 건
"이 사진이 유효한가" 하나뿐이고, 그건 ML Kit 이 이미 한다.

- 캐릭터 색은 **사진에서 직접 나온다** — `../pixelart/` 가 원본 색을 그대로 픽셀화하므로
  털색을 따로 판별할 이유가 없다
- 품종은 캐릭터 생성에 쓰이지 않는다
- 데이터셋 수집·학습·변환 공정이 통째로 사라진다

학습 코드가 필요해지면 커밋 `7922989` 에 남아 있다.
