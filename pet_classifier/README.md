# 반려동물 분류기 (온디바이스)

사용자가 올린 사진에서 캐릭터 생성에 필요한 정보를 뽑는다. **서버를 쓰지 않는다.**

## 구성

| 정보 | 방법 | 크기 |
|---|---|---|
| 종 (개/고양이/기타) | `train.py` — MobileNetV3 2-헤드 | ~5MB |
| 털길이 (단모/장모/곱슬) | 같은 모델의 두 번째 헤드 | 포함 |
| 털색 | `color.py` — 팔레트 분석, **모델 아님** | 0 |
| 이름 추천 | `names.py` — 룩업 테이블 | 0 |

합쳐서 5MB 미만. 서버 호출 0회.

## 왜 VLM 을 쓰지 않는가

**비용.** 7B VLM 서버는 GPU 상시 가동이다. 무료 앱에서 가입마다 GPU 를 태우면 감당이 안 된다.
온디바이스는 한계비용이 0이다.

**정확도.** 온디바이스로 돌릴 만한 소형 VLM(SmolVLM2-500M 등)은 세밀한 판별을 못 한다.
전용 분류기가 더 작고 더 정확하다.

**라이선스.** 검토한 한국어 VLM 대부분이 비상업이거나 조건이 불명확했다.
자세한 경위는 [LICENSING.md](../LICENSING.md) 참고.

## 품종을 뺀 이유

캐릭터 템플릿 선택에는 종·털길이·색이면 충분하다. 품종까지 맞히려면 Stanford Dogs 같은
데이터셋이 필요한데 **ImageNet 파생이라 연구용 조항이 걸릴 수 있다.**
상용 배포가 목표라 처음부터 제외했다.

나중에 품종이 필요해지면 데이터셋 라이선스를 먼저 확인하라.

## 데이터

`datasets/pets/labels.csv`:

```
filename,species,coat
dog_001.jpg,개,단모
cat_014.jpg,고양이,장모
```

`species`: 개 | 고양이 | 기타
`coat`: 단모 | 장모 | 곱슬

**팀·지인의 반려동물 사진으로 모으는 게 가장 깨끗하다.** 촬영자 동의만 받으면 되고
저작권 쟁점이 없다. 종당 100장 이상을 목표로 하라.

## 순서

```
python train.py
python export_tflite.py
python color.py <이미지>     # 팔레트 확인
python names.py             # 이름 표 확인
```

## 앱 연동

- 입력: 224x224 RGB, 0-255 (전처리 내장)
- 출력: `species` (3), `coat` (3) 각각 softmax
- 색은 `../pixelart/` 의 팔레트 양자화 결과를 재활용하면 연산이 한 번 더 들지 않는다
- **분석이 실패해도 기본 캐릭터로 폴백하라.** 사진 분석 실패가 가입 흐름을 막으면 안 된다
- `names.py` 의 표는 Kotlin 으로 옮긴다
