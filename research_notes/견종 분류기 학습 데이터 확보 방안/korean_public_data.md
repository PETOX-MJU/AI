# 한국 공공 데이터로 견종 분류기 학습 데이터 확보 (AI Hub / 공공데이터포털 / 동물보호관리시스템)

작성일: 2026-09-29. 목표: 무료 상업 모바일 앱, 모델은 온디바이스 탑재.
조사 범위: 웹 검색·페치 약 15회. AI Hub 상세 페이지는 로그인 없이 보이는 요약만 확인했고, 견종별 실제 분포(라벨 통계)는 다운로드해야 알 수 있어 확인하지 못함.

## 1. AI Hub에서 견종 라벨이 있는 개 이미지 데이터셋은?

### Takeaway
견종 필드가 있는 AI Hub 데이터셋은 세 개 확인됨: "반려동물 구분을 위한 동물 영상"(#59), "반려동물 피부 질환 데이터"(#561), "반려동물 안구 질환 데이터"(#562). 그러나 셋 다 **견종 분류용이 아님**. 주 라벨은 행동 키포인트이거나 질환 병변이고, `breed`는 메타데이터 필드일 뿐임. 공개 페이지 어디에도 견종별 수량이 없음. #561·#562 이미지는 대부분 병변·눈 클로즈업이라 전신 견종 분류에 거의 쓸모없음. 이 중 쓸 만한 후보는 #59(영상 프레임, 개 전신 bbox)뿐임.

### Cited Findings
- **반려동물 구분을 위한 동물 영상 (dataSetSn=59)**: 2020년 구축, 2021-10 갱신. 개·고양이 행동 영상 514.695시간. 가공 이미지 7,569,422장에 bbox와 15점 키포인트가 붙어 있음(목표 500만 장 대비 151.4%). JSON의 동물 정보 객체에 `breed` 메타 필드가 있음. 페이지에 견종 목록이나 견종별 수량은 없음 — [AI Hub #59](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=59)
- 원래 목적은 "반려동물 행동 분석 애플리케이션 서비스 개발"용 행동 인식 데이터 — [AI Hub #59](https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&dataSetSn=59)
- 실사용 사례: 이 데이터셋의 반려견 데이터로 행동 분석 모델을 학습한 오픈소스 프로젝트 ASAP — [GitHub SK-jeong/ASAP](https://github.com/SK-jeong/ASAP)
- **반려동물 피부 질환 데이터 (dataSetSn=561)**: 반려동물 10,000마리 이상, 이미지 50만 장 이상, 그중 질환 이미지 25만 장 이상. "반려견 7종, 반려묘 4종 피부질환으로 판정된" 문맥상 견종이 아니라 **질환 종류 수**로 읽힘(원문 문장이 모호함). 일반·스마트폰 카메라로 병변 부위를 찍었고 세포 검사 이미지는 현미경으로 촬영함. 해상도 1920x1080, JSON 폴리곤·bbox. 메타에 breed, 나이, 성별, 촬영 부위(다리/머리/몸통/연접부)가 들어 있음 — [AI Hub #561](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=561)
- **반려동물 안구 질환 데이터 (dataSetSn=562)**: 5,000마리 이상, 이미지 30만 장 이상, 그중 질환 이미지 15만 장 이상. "안구질환(반려견 12종, 반려묘 6종)" 표기상 질환 종류 수로 보임. 검안경·스마트폰·초음파·안저카메라 이미지가 섞여 있음. 메타에 `breed`(String, 필수) 있음 — [AI Hub #562](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=562)
- **반려견, 반려묘 건강정보 데이터 (dataSetSn=71520)**: 건강정보 120,365건과 메타데이터 4,000건. 품종별 호발 질병 분석이 목적이며, 요약상 이미지 중심 데이터셋이 아님 — [AI Hub #71520](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71520)
- 세 데이터셋(#59, #561, #562) 모두 상세 페이지에 "내국인만 데이터 신청이 가능합니다"라고 적혀 있음 — [#59](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=59), [#561](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=561), [#562](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=562)

### Inferences
- #59는 영상 프레임이라 같은 개가 수천 장씩 거의 똑같이 반복됨. 750만 장이라도 **서로 다른 개체 수**가 실질적인 데이터량임. 영상 단위로 train/val을 나누지 않으면 누수가 생김(shorts_classifier에서 녹화 단위로 분할한 것과 같은 문제).
- 한국 반려견 구성상 말티즈·푸들·포메라니안이 1~3위임([데일리벳](https://www.dailyvet.co.kr/news/industry/144536)). 그래서 #59도 소형견 위주일 가능성이 높음. 골든 리트리버, 닥스훈트, 웰시코기, 시베리안 허스키, 시바는 적거나 아예 없을 수 있음. 추정이며 확인 안 됨.
- #561·#562 가운데 "전신 사진"이 섞인 부분이 있다면 보조 데이터로 쓸 수는 있음. 하지만 신청 전에는 비율을 알 수 없어 기대치를 낮게 잡아야 함.

### Gaps
- #59의 견종 목록과 견종별 영상·개체 수: 공개 페이지에 없음. 데이터 설명서 PDF나 샘플 데이터를 받아야 확인 가능.
- "펫 안면 인식"이나 "반려견 비문" 데이터셋이 AI Hub에 있는지: 검색으로 확인하지 못함(비문 관련 결과는 민간 기업 기사뿐이었음).
- 구 AI Hub URL(aihub.or.kr/aidata/34146)도 검색에 나왔지만 내용은 확인하지 않음.

## 2. AI Hub 약관: 학습 모델의 상업적 이용, 데이터 재배포, 해외 접근, 신청 절차

### Takeaway
**학습한 모델을 상업 서비스에 쓰는 것은 허용됨.** 조건은 원본 데이터가 서비스 밖으로 새어 나가지 않는 것. **데이터 자체**(가공본 포함)의 재배포·판매·제3자 제공은 금지되고, 국외 반출과 국외 소재자의 이용에는 NIA와 별도 합의가 필요함. 개 관련 데이터셋은 모두 "내국인만 신청 가능"이고, 결과물에는 "한국지능정보사회진흥원 사업결과"라고 출처를 표시해야 함.

### Cited Findings
- 데이터셋 판매: "AI 허브에서 제공하는 AI 데이터셋의 판매 등 상업적 이용을 희망하는 경우 수행기관과 별도 협의가 필요합니다." — [AI Hub 이용정책](https://www.aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105)
- 재배포 금지: 승인 없이 "다른 법인, 단체 또는 개인에게 열람하게 하거나 제공, 양도, 대여, 판매하여서는 안됩니다." — [AI Hub 이용정책](https://www.aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105)
- 국외 반출: "본 AI데이터 등의 국외 반출을 위해서는 수행기관 등 및 한국지능정보사회진흥원과 별도로 합의가 필요합니다." 국외 소재 법인·단체·개인이 이용하려 할 때도 같은 합의가 필요함 — [AI Hub 이용정책](https://www.aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105)

- 학습 모델의 상업적 이용(검색 요약에 나온 이용정책 문구): 원본 데이터나 단순 가공한 원본이 서비스 저장·운영 과정에서 외부로 유출되지 않는다면, 학습한 모델을 상업 서비스에 쓸 수 있음. AI 데이터는 AI 학습 모델 학습 용도로만 쓸 수 있음 — [AI Hub 이용정책](https://www.aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105) (정책 페이지를 직접 페치했을 때는 이 문구의 원문을 뽑지 못함. 검색 요약 기준.)
- 공식 답변을 전해 들은 2차 출처: 제3자 GitHub 이슈에 AI Hub 답변 메일이 요약돼 있음. ### Inferences
- 온디바이스 모델(가중치만 들어 있음)을 무료 앱에 넣는 것은 "학습한 모델의 상업적 이용"에 해당하므로 허용 범위로 보임. 단 다음은 금지 쪽에 걸림.
  - 앱 안에 학습 이미지(예: 견종 예시 사진)를 번들하는 것
  - 크롭한 이미지나 라벨 파일을 공개 GitHub에 올리는 것
  - 팀원·외주에게 원본을 넘기는 것
  - 해외 클라우드(예: 미국 리전 Colab/GPU)로 원본을 올려 학습하는 것. 해외 클라우드 학습이 "국외 반출"에 해당하는지는 약관만으로 불명확함. 위 GitHub 이슈의 KISA "국내 IP" 판단 언급을 보면 보수적으로 해석하는 게 안전함.

- 출처 표시 의무는 앱의 오픈소스 라이선스·크레딧 화면에 "본 모델은 과학기술정보통신부·한국지능정보사회진흥원의 AI Hub 데이터를 활용하여 학습함" 같은 문구를 넣어 해결하면 됨.

### Gaps
- 약관 개정 이력이나 2024~2026년 개방 정책 변경(예: 외국인 이용 허용): 확인되는 공식 발표를 찾지 못함. 이용정책 페이지에도 개정일이 보이지 않음.
- 보안서약서 요구 여부: 이용정책 본문에서 찾지 못함. 일부 민감 데이터셋(의료 등)만 별도 절차가 있는 것으로 알려져 있으나 출처로 확인하지 못함.
- 승인까지 걸리는 시간: 공식 수치 없음. 공개 데이터셋은 즉시 또는 1~2일 안에 승인된다는 경험담이 흔하지만, 이번 조사에서 인용할 만한 출처는 찾지 못함.

## 3. 공공데이터포털·동물보호관리시스템(유기동물 공고) 사진의 라이선스와 품종 신뢰도

### Takeaway
농림축산검역본부의 구조동물 조회 API(data.go.kr 15098931)는 **"이용허락범위 제한 없음"**, 무료, 자동승인임. 품종 코드(kindCd)와 사진 URL(popfile)을 주므로 기술적으로는 데이터를 모으기 가장 쉬움. 그러나 유기견의 **약 79%가 비품종(믹스견)**이고, 품종 라벨은 보호소 직원이 눈으로 보고 입력한 값이라 신뢰도가 낮음. 목표 견종(골든, 닥스, 코기, 허스키, 시바)의 표본도 매우 적을 것으로 예상됨. 사진 저작권도 흐림: 찍은 주체가 지자체·위탁 보호소이고, 사진마다 공공누리 표기가 붙어 있지 않음.

### Cited Findings
- **국가동물보호정보시스템 구조동물 조회 서비스**(농림축산식품부 농림축산검역본부): 이용허락범위 "제한 없음", 무료. 개발·운영 계정 모두 자동승인. 개발 계정은 하루 10,000건, 활용사례를 등록하면 트래픽 증설 가능. 2022-02-11 등록, 2026-01-23 수정. 반환 필드에 kindCd(품종), popfile(사진 URL), 시도·시군구, 보호소 정보가 포함됨 — [data.go.kr 15098931](https://www.data.go.kr/data/15098931/openapi.do)
- 공공누리 유형(공공누리 공식 설명)
  - 제1유형: 출처표시만 요구. 상업적 이용과 2차 저작물 작성 가능
  - 제2유형: 출처표시 + 상업적 이용금지
  - 제3유형: 출처표시 + 변경금지
  - 제4유형: 출처표시 + 상업적 이용금지 + 변경금지
  - 출처: [공공누리 유형 안내](https://www.kogl.or.kr/info/license.do)
- 2023년 유기견 80,138마리 가운데 품종견은 20.8%(16,665마리), 비품종견은 79.2%(63,473마리)였음. APMS 데이터를 동물자유연대가 분석한 결과임. APMS에는 "믹스견, 도사 믹스견, 치와와믹스견, 시바믹스견, 진도믹스" 같은 표기가 제각각 섞여 있음 — [데일리벳](https://www.dailyvet.co.kr/news/policy/227916)
- 2024년 유기동물 발생은 106,824마리로 5년 연속 감소함 — [데일리벳](https://www.dailyvet.co.kr/news/policy/248072)
- 이 API를 쓰는 민간 서비스로는 포인핸드 유형의 앱, 보호소 조회 웹 등이 있음 — [데일리벳 전국 동물보호센터 데이터 개방](https://www.dailyvet.co.kr/news/policy/123184), [GitHub PetService_Web](https://github.com/JmKanmo/PetService_Web)

### Inferences
- "이용허락범위 제한 없음"은 API가 주는 **데이터(메타데이터)**에 대한 표시임. popfile이 가리키는 사진 자체의 저작권이 공공누리 제1유형처럼 명시된 것은 확인되지 않음. 사진 촬영자는 지자체 공무원이나 위탁 보호소(민간)이므로, 민간 위탁 보호소가 찍은 사진은 공공저작물이 아닐 가능성이 있음. 학습용으로만 쓰는 것은 저작권법 TDM(텍스트·데이터 마이닝) 예외 논의와도 얽혀 있어서, 법률 검토 없이 "상업 이용 OK"로 단정할 수 없음.
- 품종 라벨 노이즈가 큼. 코기믹스를 "웰시코기"로, 허스키 닮은 믹스를 "시베리안 허스키"로 입력하는 식의 오류를 예상해야 함. 그대로 학습하지 말고 **후보 수집용**으로만 쓰고 사람이 다시 라벨링하는 게 현실적임.
- 견종별 기대 수량(추정): 2023년 품종견은 연 16,665마리이고, 그중 다수가 말티즈·푸들·포메·진도·시바·치와와 같은 소형견이나 진도·시바로 추정됨. 골든 리트리버·웰시코기·허스키·닥스훈트는 연 수십~수백 건 수준일 것으로 보이며 확인되지 않음. 사진은 대부분 1~3장이고 저해상도에 철창·케이지 배경임. API 과거 공고를 몇 년치 긁으면 진도·시바·말티즈·푸들은 수천 장 확보가 가능할 수 있음. 반면 대형 수입견은 부족할 가능성이 큼.
- 한국 특화 견종(진도, 풍산, 삽살, 진도믹스)에는 이 데이터가 거의 유일한 대량 소스라는 가치가 있음.

### Gaps
- 공고 사진(popfile)의 저작권·공공누리 유형 표기: 확인하지 못함. animal.go.kr 이용약관을 직접 확인해야 함.
- API로 받을 수 있는 과거 공고의 보존 기간과 견종별 실제 건수: API를 직접 집계해야 알 수 있음(서비스키 발급 후 kindCd별 count).
- 2024~2025년 견종별 유기견 통계: 찾지 못함.

## 4. 기타 한국 소스, 실무적 확보 가능량, 접근 절차와 소요 시간

### Takeaway
견종 분류 전용으로 공개된 한국 공공 이미지 데이터셋은 찾지 못함. 국립축산과학원이나 공모전 데이터 중 조건이 명확한 견종 이미지 소스도 이번 조사에서는 확인되지 않음. 현실적인 조합: AI Hub #59를 신청해(개인, 내국인) 견종 메타를 집계한 뒤 보조 데이터로 쓰고, 유기동물 API는 진도·믹스 등 한국 특화 클래스의 후보 풀로 쓰고, 주력 데이터는 해외 공개 데이터셋에서 가져오는 것.

### Inferences
- 접근 단계와 예상 소요 시간
  1. AI Hub 회원가입(본인인증, 내국인) 후 #59 다운로드 신청. 공개 데이터는 승인이 대체로 빠르다고 알려져 있음. 수백 GB에 이르는 영상·이미지 다운로드에는 전용 다운로드 툴과 대역폭 기준으로 며칠이 걸릴 수 있음.
